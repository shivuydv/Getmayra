# MYRA - Anime AI Companion & Smart Assistant

MYRA is a gorgeous anime AI girlfriend, loving companion, and personal phone assistant built for Android. It combines advanced AI reasoning (Gemini/ChatGPT) with ultra-realistic speech (ElevenLabs) and deep Android system integration.

## 🌟 Key Features
- **Dual Visual Modes**: Switch between a cute expressive Anime Girlfriend and a sound-reactive Maya Cyber HUD Orb.
- **Deep Android Automation**: Control your phone via voice—open apps (WhatsApp, Spotify, Instagram), toggle flashlight, check battery/RAM stats, and more.
- **WhatsApp Reader**: Maya can listen for incoming WhatsApp messages and read them aloud to you while her session is active.
- **Live Wallpaper**: Bring Maya to your home screen! A fully animated live wallpaper that breathes, looks around, and reacts to your touch.
- **Guardian AI**: Integrated call screening and voice biometrics to protect against deepfake scams and robocalls.
- **Expressive AI**: Choose between "Nakhre & Sassy", "Sweet & Loving", or "Friendly" personality modes.

## 🛠 Tech Stack
- **UI**: Jetpack Compose (Material 3)
- **Language**: 100% Kotlin
- **AI Engines**: Google Gemini 1.5 Flash (Primary), OpenAI GPT-4o-mini (Optional)
- **Voice**: ElevenLabs AI Voice (Ultra-realistic) & Native Android TTS
- **Computer Vision**: Google ML Kit (QR/Barcode Scanner)
- **Services**: Foreground Services for background listening, Accessibility Services for screen reading.

## 🚀 Installation
1. Download the latest `MYRA-v1.0.0.apk` from the [Releases](https://github.com/YOUR_USERNAME/MYRA/releases) page.
2. Open the APK on your Android device.
3. Enable "Install from Unknown Sources" if prompted.
4. Launch MYRA and grant **Microphone** and **Notification Access** for full functionality.

## 🔑 Configuration
To unlock the full potential of MYRA, you will need your own API keys (Zero budget usage possible via Free Tiers):
1. **Google Gemini**: Get a free API key from [Google AI Studio](https://aistudio.google.com/).
2. **ElevenLabs**: Get an API key from [ElevenLabs](https://elevenlabs.io/) for high-quality voice synthesis.
3. **OpenAI**: (Optional) For alternative reasoning.

Enter these keys in the **Key Icon** 🔑 menu within the app.

## 🛡 Privacy & Safety
- **Local Keys**: Your API keys are stored securely on your device's private storage.
- **Microphone**: MYRA only listens when a session is active (indicated by a foreground notification).
- **Safety**: System automations (like calls or SMS) always require manual confirmation from the user.
